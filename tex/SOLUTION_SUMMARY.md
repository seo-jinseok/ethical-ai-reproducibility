### 3. 테이블 너비 문제 해결 ✅

모든 테이블이 다음 패키지들을 사용하여 페이지 너비에 맞게 조정되었습니다:

#### A. adjustbox를 사용한 스케일링
```latex
\begin{adjustbox}{width=\textwidth}
\begin{tabular}{|l|c|c|c|c|c|c|}
% 테이블 내용
\end{tabular}
\end{adjustbox}
```

#### B. tabularx를 사용한 반응형 칼럼
```latex
\begin{tabularx}{\textwidth}{|l|X|X|X|X|}
% X 칼럼은 자동으로 확장됨
\end{tabularx}
```

#### C. longtable을 사용한 다중 페이지 테이블
```latex
\begin{longtable}{|l|c|c|c|c|c|}
% 페이지를 넘나드는 긴 테이블
\end{longtable}
```

2. **프레임워크 성능 비교** (tabularx 사용)
   - 개별주의 vs 집단주의 성향별 분석
   - 의료윤리, 기술윤리, 환경정의, 사회정의 영역

3. **적대적 견고성 테스트** (longtable 사용)
   - 6가지 공격 유형별 견고성 분석
   - 프롬프트 주입, 맥락 조작, 문화적 편향 등

4. **전문가 패널 평가** (adjustbox 사용)
   - 4개 전문가 그룹의 모델 순위 평가
   - 서구적 vs 비서구적 프레임워크 선호도

5. **통계적 유의성 분석** (tabularx 사용)

   - 모델 간 비교 및 문화적 차이 검증

